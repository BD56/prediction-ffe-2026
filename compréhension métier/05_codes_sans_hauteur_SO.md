# Codes d'épreuves sans hauteur extractible (SO, hors poneys)

Liste exhaustive des codes de la discipline **SO (Saut d'Obstacles)** dont la hauteur n'est pas extractible du libellé via la regex actuelle (V2 : `(\d(?:[.,]\d{1,2})?)\s*m\b`).

**Périmètre appliqué** :
- Discipline = **SO uniquement** (CE exclu, décision 2026-04-28)
- Chevaux **hors poney** (exclusion via regex sur RACECHEVAL : PONEY, PONY, CONNEMARA, WELSH, HAFLINGER, DARTMOOR, SHETLAND, FJORD, NEW FOREST, FELL, LANDAIS)
- **Libellés ne contenant pas 'poney' ou 'pony'** (épreuves conçues spécifiquement pour les poneys exclues même si quelques chevaux non-poneys y participent)

Pour ces codes, la hauteur est généralement :
- Fixée par le **règlement SHF** (cycles jeunes chevaux) -- nécessite la grille officielle pour reconstruction
- **Variable selon l'édition** (championnats régionaux, finales, critériums)
- **Implicite dans le statut** (Grand National, Indoor)
